# 指示書07 Threads制作（役割定義・カルーセル等）

出典：教材第8章（講義24〜27）。実測（競合5アカウント、@shiba_9646_ai・@maki_shiba_reset の運用実績）との使い分けを明記する。

## 役割定義（講義24）：Instagram＝表、Threads＝裏

| | Instagram（表／FRONT STAGE） | Threads（裏／BACK STAGE） |
|---|---|---|
| 中身 | 完成された世界観・カタログ（視覚情報） | 脳内・プロセス・言語化（思考の過程） |
| 見せるもの | 「結果」 | 「人間味」・プロセス |
| 役割 | 認知獲得・集客の入り口 | 信頼構築・ファン化の深部 |

### 相互送客の循環モデル
1. **インスタ解説（表）**：画像やリールで視覚的に興味を惹き、認知を獲得する
2. **Threads深掘り（裏）**：制作の背景や思考プロセスを濃いテキストで言語化し、ファン化と信頼構築を行う
3. **インスタ図解（まとめ）**：Threadsで反応が良かった内容を構造化して図解にし、「保存される情報」として再パッケージする

このループで、2つのアプリで「1つの体験」を作る。

## カルーセルの勝ちパターン（講義25）

ジャンルによりA／Bの2パターンに分かれる。自分のジャンルがどちらか決め、プロフィールと固定投稿で宣言する。

### パターンA 世界観・共感系（写真＋一言、紙芝居スタイル）
- 対象：暮らし、Vlog、美容など「雰囲気」が重要なジャンル
- 形式：目を引く写真に短文を一言だけ添える。理屈より感性。文字過多はノイズ（画像内の細かい文字は拡大されない）
- **最適枚数は3〜5枚**（滞在時間最大化 × 離脱最小のスイートスポット）。10枚は冗長で離脱を招く。1〜2枚は滞在時間が稼げず評価の土俵に乗らない
- 素材：中途半端な素人写真はノイズになる。撮影スキルがない場合はAI生成画像で画風・キャラクターを固定し、世界観を統一して量産する（同じキャラ・違うポーズ・違う表情の連作が可能）。重要なのはリアリティではなくタイムラインでの可視性と統一感
- ※@maki_shiba_reset への適用注意（本指示書の判断）：マキ垢で実測で唯一反応したのはストーリー型の自己開示（表示279）であり、「写真＋一言」単独の実績はない。A型は補助として使い、主型はストーリー型に置く。AI生成画像での世界観統一は、既定の「アニメ中心」方針と相性がよい

### パターンB 実用・ノウハウ系（大文字スライド、プレゼン型）
- 対象：ビジネス、ガジェット、知識系など情報の価値が高いジャンル
- 形式：画像には大きな見出しと図解のみ。細かい文字の詰め込みはNG。詳細な説明は本文（キャプション）で語る（Threadsは「読む」モードの媒体）
- 鉄則チェック：
  - [ ] 拡大不要の文字サイズか（ピンチアウトが必要な時点で負け）
  - [ ] 情報を「削る勇気」を持てたか（画像は見出し＋シンプルな図解だけ）
  - [ ] 詳細を本文で補完したか（画像で興味を引き、本文で解説する役割分担）
- ※@shiba_9646_ai は軸としてはB側だが、実測の主型は短文テキスト投稿（51〜117字級の一次情報）。カルーセルB型は「図解で残す価値があるネタ」のときの選択肢とし、日常の主型はテキスト短文に置く（判断事項）

### 正解の見つけ方（3ステップ）
1. まず発信してみる（質より量でテストしデータを蓄積）
2. For Youに流れる同ジャンルの他者投稿を観察する（写真型か文字型か、傾向を把握）
3. 界隈の正解型に合わせる（自分の好みより市場の答えに従う）

## アイコンと発信内容の整合性（講義26）

- アイコンと内容が一致すると一瞬で納得されフォローされる（教材の例：法衣姿アイコン＋説法→「本物だ」）。乖離すると「胡散臭い」と即離脱（私服の若者アイコン＋説法）。
- 視線動線は「本文→アイコン→本文」。アイコンは本文の信頼を裏付ける装置として設計する。

## プロフィール文の最適化（講義27）

プロフィールは自己紹介ではなく、ユーザーへの約束の場。Threadsは文字主体で、アイコンとプロフィール文でフォロー判断が即決される。

- 「何を発信しているか」を専門分野・ジャンルの一言で定義する（「日常」「思いつき」はNG）
- 「見るとどうなれるか」を数値・ターゲットで明文化する：
  - NG「美容情報」→ OK「30代が1ヶ月で肌質改善する知識」
  - NG「仕事術の発信」→ OK「残業−5h/週を実現するエクセル術」
  - NG「節約生活の記録」→ OK「年100万貯めて海外旅行に行く家計簿」
  - NG「前向きになれる言葉」→ OK「自己肯定感ゼロから自分を愛せる毎日へ」
- 構造の詳細（名前欄、実績行、受け取り口）は指示書01の手順4に従う。

## リンク設定の鉄則（講義27）

- [ ] 公式LINEへ直リンクしていないか（Threadsユーザーは外部遷移と個人情報取得の気配に強い警戒心を持つ。**直リンクはNG**）
- [ ] クッションページ（note／ブログ）を挟んだか（まず「読み物」で信頼を得てからLINEへ促すのが正解ルート）
- [ ] リンク先で「得られる未来」が明示されているか（ただURLを貼るだけにしない）

## Threads運用 開始前リスト（第8章まとめ）

- [ ] アイコン整合：発信内容とビジュアルが一致しているか
- [ ] プロフィール明文化：「見るとどうなれるか」を具体的ベネフィットで明記し、note等への動線を確保したか
- [ ] 運用スタイルの決定：パターンAかBかを選び、プロフィールと固定投稿で宣言したか
