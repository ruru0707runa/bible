## 1. 教材の性格（一言要約）

- 3教材の中で唯一、**Instagramを主戦場として体系化**した教材。動画（リール）の制作規定（音圧、編集、セーフティゾーン、タイトル辞書）と運用ルーティン（頻度、分析指標、SEO）の「規定集」としての密度が高い。
- Threads編は第8〜10章の45ページで、「Instagram＝表／Threads＝裏」の役割分担、カルーセルの型、拡散テクニック、noteクッション動線が中心。Threads単体の投稿設計（文字数、頻度、型のバリエーション）はシンスレッズほど細かくない。
- AI活用・自動化の話はほぼない（AI生成画像の推奨、スケジューラへの言及程度）。レオの領域とは重ならない。
- 思想面はシンスレッズと同系：「設計が先」「具体性」「一次情報に近い自分事化」「リスト化して売る」。新しいのは「減点法」「カニバリゼーション回避」「滞在時間の設計」というInstagram動画の評価設計の言語化。

## 2. 既存2教材との比較

→ 重複が多いのは「設計→集客→リスト→販売」という事業構造の部分。バイブルの新規性は構造ではなく、**Instagram動画の制作・評価の具体規定**と**Threadsのカルーセル型・拡散作法**にある。

### 2.2 バイブル独自の要素（既存2教材にないもの）

1. **減点法とノイズ規定**：音圧−12〜−9 LUFS、テロップ空白0秒、ジェットカット（フィラー完全削除＋1.05〜1.1倍速）、3秒ルール（同じ絵面を3秒以上続けない）、セーフティゾーン数値（右15%・下部20%）。シンスレッズ・レオには動画編集の数値規定はほぼない（レオのリールテンプレは「1〜2秒でシーン切替、字幕1シーン1行」という方向性のみ）。
2. **カニバリゼーション回避と頻度の最適点**：AI評価期間48〜72時間（教材の主張）を根拠に「Instagramは3日に1回」。既存2教材は量を推す側で、この発想はない。
3. **単一KPI主義**：見る指標をスキップ率（3秒維持率65%）1つに絞る。シンスレッズは詳細タップとプロフィールアクセスを最重要とし、指標は複数。レオは重いシグナルとして複数を挙げる。
4. **資料集**：パワーワード辞書、穴埋めタイトルテンプレート（掲載分1〜20）、配色70/25/5、サムネ4訴求型。即日使える「辞書」としての実用部品。
5. **Threadsカルーセルの型**：パターンA（写真＋一言、3〜5枚）／パターンB（大文字スライド＋本文で詳細）。シンスレッズはテキスト投稿中心で、この画像型の規定はない。
6. **Threads拡散の作法**：自己再投稿の24時間ルール、コバンザメ（リプ）戦略の3条件、エンゲージメント・ベイト3類型、ツリー式寸止めの未完フレーズ集。シンスレッズのタップ投稿・引用2割と部分的に重なるが、リプ戦略とベイトの体系化はバイブル側が詳しい。
7. **noteクッションの価格設計**：低単価note 100〜1,000円で「決済体験」を作り財布のブロックを外す、という段階設計。シンスレッズのnote導線は低単価の価格帯と心理設計まで踏み込まない。

### 2.3 矛盾・緊張関係がある点

1. **投稿頻度（最大の矛盾）**
   - バイブル：Instagramは3日に1回（カニバリ回避）。ただしこれは動画（リール）の評価期間を前提にした主張。
   - シンスレッズ：Threads単体で伸ばすなら1日10投稿が基準・最低5。フェーズ1（〜100人）も1日5〜10。
   - 実測（競合5アカウント）：2.4〜7本/日で「量×固定導線」が共通構造。
   - → 媒体で分けて考えるべき緊張関係。バイブルの頻度論はInstagramのリールの話であり、Threadsのテキスト投稿にそのまま適用する根拠は教材内にない。Threadsについてはバイブル自身が頻度の数値基準を持たず（第8・9章は型と会話量の話）、シンスレッズ＋実測の「量」側が優先される。**判断事項として指示書00に明記した。**
2. **長文か短文か（Threads）**
   - バイブル：フォロワー〜1万は短文3〜5行（結論→一言根拠→CTA）、1万超で長文教育（講義35）。
   - シンスレッズ：3部構成の有益投稿＋PREP法が王道で、長文も許容。ただしフェーズ制で量と型を使い分ける。
   - 実測：勝者は全員51〜117字の超短文中心。長文ノウハウ保存型は天井が低い。
   - → しばの現フェーズ（フォロワー約400）では両教材とも「短文側」で一致する。バイブルの「1万超で長文」は未検証の段階論として扱う。
3. **プロフィール設計**
   - バイブル：宣言型15字×4行（ベネフィット→対比→武器→卒業）。
   - シンスレッズ：名前＝名前＋肩書き、本文は行ごとに役割（価値提示→学べること→実績→行動喚起）、必須要素は発信内容・実績・フォローメリット。
   - → 矛盾ではなく粒度の違い。バイブルの4行は「Instagramの自己紹介文」の書き方、シンスレッズはThreadsの名前欄＋本文の構造規定。併用可能。ただし実測では「実績数字をプロフィールに集約」が勝者共通（なりタイ、ケム）で、バイブルの4行には実績の置き場が明示されていない。併用時は実績行を足すのが安全。**判断事項として指示書01に明記した。**
4. **指標の優先順位**
   - バイブル（Instagram）：スキップ率1本化。
   - シンスレッズ／レオ（Threads）：詳細タップ、プロフィールアクセス、滞在時間、コメント等の複合。
   - → 媒体別の指標なので矛盾ではないが、「指標は1つに絞る」という運用姿勢はThreads側に持ち込まない。Threadsはバイブル自身も再投稿×滞在時間×会話量の複合で語っている（第9章）。
5. **外部リンクとLINE誘導**
   - バイブル：ThreadsからLINEへの直リンクはNG、noteクッション必須。自リプへのリンク隔離。
   - シンスレッズ：本文リンクは避けコメント欄へ。固定投稿＋プロフィールに収益導線を常設。
   - 実測：勝者はプロフィール末行に無料の置き場を常時置き（ケム、まな）、Saiはリンク誘導投稿を告知専用枠として全体の25%回している。
   - → 「本文に直リンクは置かない」は3者一致。「プロフィールと固定に常設する受け取り口」は実測・シンスレッズ側が強く、バイブルの「クッション必須」とは緊張するが、プロフィールリンク自体はバイブルも前提にしている（講義27はリンク先の設計の話）。実務上は「本文直リンクなし＋プロフ・固定に常設＋noteクッション」で両立する。
6. **AI・自動化の位置づけ**
   - バイブル：AIは画像生成と予約投稿程度の道具。レオとは補完関係で矛盾なし。ただしバイブルの頻度論（3日に1回、1本を伸ばし切る）とレオの量産思想（テンプレ×変数で量産）は、Instagram動画については正面からぶつかる。使い分けは「量産するのは台本・素材のバリエーション、投下ペースは評価を見て決める」が落としどころ。**判断事項に記録した。**

## 3. しばの実測との照合

実測の土台：@shiba_9646_ai Threads第1週（10/31〜11/6、21本）＝フォロワー404→403（−1）、週間表示合計2,251、いいね18、返信4、再投稿0。競合5アカウント実測（2026-11-04）＝全員が文字数中央値51〜117字の超短文中心、日常投稿2.4〜7本/日、伸びるのは一次情報・実績数字・証拠、ノウハウ保存型の天井は低い、フォロー転換は固定投稿＋プロフィールに常設。

### 3.1 実測と一致する教材の主張

1. **短文が標準形（講義35のPHASE 1）**：バイブルの「〜1万は3〜5行の短文」は、勝者5人の中央値51〜117字と方向が一致する。しば垢の第1週が最大500字の長文単発で表示最大55に留まった事実とも整合する（長い＝読む義理がない、という教材の説明と一致）。
2. **一次情報・証拠が伸びる**：バイブルの「自分事化」「日常シーンへの翻訳」「結果先出し」は、実測の上位（Saiの証拠写真シリーズ平均いいね133、なりタイの一次情報TOP5、ケムの節目報告）と同方向。逆に純ノウハウが上位に入らない点も、バイブルが「ノウハウ提示だけでは無意味、悩み解決の提示が要る」とする点と一致する。
3. **フォロー転換は固定＋プロフィール**：バイブルの講義27（プロフィール＝約束の場、ベネフィットの明文化）と、実測の「固定投稿＋プロフィールに常設が勝者共通」は一致する。しば垢の連載目次型の固定が最も弱い形だった点も、バイブルの「プロフィールは自己紹介ではなく未来の提示」という基準から見れば同じ結論になる。
4. **会話量が反応を作る（講義28・32）**：実測では上位投稿は返信が厚く、本人の返しが反応と相関した（なりタイ、しゃちの挨拶枠）。バイブルの「会話の往復を最重要視」「コメント欄の滞在時間も評価」はこの実測と一致する方向。
5. **定型の反復**：バイブルの「一貫性（ジャンル認知の固定）」「テンプレ・プリセット化」は、実測の勝者の定型枠の反復（しゃちの定型挨拶、Saiの定型句、ケムの冒頭型統一）と一致する。しば垢第1週は型の反復より1本ごとの作り込みに寄っており、ここも教材と実測が同じ方向を指す。
6. **本文にリンクを置かない（講義33・36）**：シンスレッズとも一致し、実測でも本文リンクで伸びた例は確認されていない（Saiのリンク投稿は告知枠として低反応を許容）。

### 3.2 実測と食い違う・実測が支持しない教材の主張

1. **「3日に1回」の頻度論をThreadsに持ち込むこと**：バイブルの頻度論はInstagram動画の評価期間（48〜72時間、カニバリ）を根拠とする。Threadsの実測では2.4〜7本/日が勝者の実態で、しば垢の1日3本でも量不足側だった。バイブル頻度論はThreadsには適用しない（媒体を分ける）。なおInstagram側でも、しば垢は現在リール9本テスト（1日1本×9日）を実施中で、この実測が取れれば頻度論を自前で検証できる。
2. **ベイト・参加型の効き目（講義32）**：バイブルは二者択一や質問型のベイトを拡散の鍵とするが、しば垢第1週の参加型・需要確認型は返信0〜2で機能しなかった（フォロワー数百規模では「答える側の母数」がいない）。マキ垢でも参加型は表示18・返信0。ベイトは「母数ができてから効く手法」として後順位に置くべきで、教材の汎用的な推奨とは温度差がある。
3. **予告・ティーザー型の位置づけ**：バイブルは寸止め・ティーザーを滞在と誘導の主力技術として扱うが、実測では予告単独の投稿は最も弱い部類だった（マキ垢の予告型は表示11）。寸止めは「中身のある投稿の接続技術」としては使えるが、予告そのものを投稿の主役にする使い方は実測が支持しない。

### 3.3 未検証（教材の主張のまま、採用判断は保留）

以下は教材が数値や仕様として断言するが、しばの実測でも外部情報でも確認できていないもの。指示書内では「教材基準（未確認）」と明記して使う。

- スキップ率の合格ライン35%以下／3秒維持率65%以上で発見タブ露出が始まる（講義15、巻末）
- AIの評価期間48〜72時間とカニバリゼーションの発生（講義16）
- 外部リンク投稿の表示制限（ペナルティ）の存在と程度（講義36）。「本文に置かない」運用自体は他教材・実測と一致するため低リスクだが、仕様としての断定はできない
- ストーリーズ閲覧率10〜20%、LINE／メルマガの成約率が5〜10倍（講義19）
- 視聴者の99%はスマホ（資料3）、損失反応は「得」の2倍（資料1）等の心理・統計数値
- InstagramのBEST TIMING（リール18〜20時、ストーリーズ朝7時・昼12時・夜20時、講義21）
- 自己再投稿の24時間ルールによる再評価ブースト（講義29）
- 画像×本文の往復動線で滞在時間が「倍増」する（講義28）
- 低単価note（100〜1,000円）の決済体験が高単価への抵抗を「劇的に下げる」効果量（講義37）
- タイトルテンプレート「30選」のうち21〜30（本テキストでは1〜20のみ掲載を確認。残りは未確認）

## 4. しばの2アカウントへの含意（分析としての見立て）

- **@shiba_9646_ai（AI×SNSマーケティング軸）**：Threadsの型はパターンB（実用・ノウハウ系）に近いが、実測が示す主型は「短文の一次情報つぶやき＋固定・プロフィールの常設導線」。バイブルから取り入れる価値が高いのは、(1)動画の制作規定（いま走っているリールテストの品質基準として即効性がある）、(2)コバンザメ（リプ）戦略と引用の作法（返信運用の具体手順として）、(3)noteクッション＋低単価の動線設計（第2週の数字公開→noteの流れと接続できる）、の3点。頻度論とベイトは実測優先で抑える。
- **@maki_shiba_reset（マキの再起動軸）**：パターンA（世界観・共感系）の対象ジャンルに近い。ただし実測で唯一反応したのはストーリー型（表示279）で、「エモい写真＋一言」単独ではなく物語性のある自己開示だった。バイブルのA型をそのまま当てはめるより、「写真＋一言」は補助にし、ストーリー型を主型にするのが実測に沿う。AI生成画像で世界観を統一する提案は、マキ垢の「アニメ中心」という既定方針と相性がよい。
- 両アカウント共通：バイブルの制作規定（減点法、セーフティゾーン、タイトル辞書）は媒体・ジャンルを問わず流用できる「品質の下限」として採用価値が高い。逆にアルゴリズム仕様の断定部分は、自分の数字で検証してから信じる、が3教材を通じた安全な運用姿勢になる。

## 5. 判断事項（本分析・指示書化での判断）

1. **頻度は媒体で分離した**：指示書05ではInstagram動画＝バイブルの「3日に1回」を教材案として記載し、Threads＝シンスレッズ＋実測に基づく「量と会話」を優先基準として明記した。バイブルの頻度論をThreadsに適用する記述は指示書に含めていない。
2. **数値基準は「教材基準（未確認）」と表示した**：スキップ率65%、評価期間48〜72時間、BEST TIMING等は、指示書内でも出所を教材と明記し、保証値として扱わない。
3. **プロフィールは2教材を併用設計にした**：指示書01ではバイブルの宣言型4行をInstagram用、シンスレッズの型＋実績行をThreads用とし、実測（実績数字の集約）を優先した。
4. **ベイト・予告型は後順位にした**：指示書08では、フォロワー数百規模での実測（返信0〜2）を根拠に、ベイトは「母数ができてから」の手法として注意書きを付けた。
5. **タイトルテンプレートは掲載分のみ収録した**：教材まとめに「30選」とあるが本文で確認できた1〜20のみを指示書・プロンプト集に収録し、21〜30は未確認と明記した。
6. **今回の範囲外**：投稿案の作成・予約・プロフィール変更の実施は含めない（指示書は実行可能な手順の形まで）。
